# VIGÍA training material

Two guides, two audiences, two languages, one rule: the verdict is sealed
before anyone writes a word about it, and nothing in this directory can change
it.

## Worked examples

`examples/` holds reports **generated by the renderer** from real sealed bundles
under `results/`. They are pinned by `tests/test_training_worked_examples_pinned.py`:
if the renderer changes, the examples must be regenerated and committed with it,
so they never drift from what the tool actually produces.

## Generating your own

```bash
# From any sealed bundle, both audiences, both languages, next to the bundle:
python3 -m vigia.report path/to/CASE_bundle.json

# One variant to the terminal:
python3 -m vigia.report path/to/CASE_bundle.json --audience junior --lang es --stdout

# At investigation time (Mode 1), as siblings of the bundle:
python3 vigia_agent.py --evidence <dir> --case-id CASE-1 --audience all
```

The reports are Markdown files named `<stem>_report_<audience>_<lang>.md`.
They are never written inside `VIGIA_EVIDENCE_DIR`, never inside the bundle, and
carry no generation timestamp: the same bundle always yields the same bytes.
