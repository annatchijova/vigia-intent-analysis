Variables de entorno
VIGIA_HMAC_KEY y KASSANDRA_SALT ya están en GitHub Secrets. Para correr localmente con cadena de custodia completa, exportarlas manualmente.
Generar secrets locales
export VIGIA_HMAC_KEY="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
export KASSANDRA_SALT="$(python3 -c 'import secrets; print(secrets.token_hex(16))')"
export VIGIA_EVIDENCE_DIR="/tmp/vigia_evidence"
VariableDescripciónEstado
VIGIA_HMAC_KEY Clave HMAC para cadena de custodia de logs (hex, ≥32 bytes) GitHub Secret ✓
KASSANDRA_SALT Salt para derivar session nonce del Protocolo Kassandra GitHub Secret ✓
VIGIA_EVIDENCE_DIR Directorio base de evidencia forense opcional local
VIGIA_LLM_BACKEND Backend LLM para narrativa: ollama o anthropic opcional
VIGIA_ENFORCE_STDIO Bloquea HTTP sin auth en el servidor MCP producción
VIGIA_STRICT_MODEL_CHECK Verifica SHA-256 del modelo CLIP antes de cargar producción
