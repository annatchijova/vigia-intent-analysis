## ENGLISH

### What Is This Module?

This module is a **deterministic forensic reconstruction engine** designed to extract, classify, and temporally order digital evidence from Windows Registry hives. It operates as an analytical instrument that treats registry entries as sensor readings emitted by the operating system. To prevent evidence contamination, the engine enforces strict input validation, confines file access to explicitly authorized directories, and invokes external parsing tools via isolated argument vectors—never through shell interpretation. All temporal reasoning is performed with **deterministic integer arithmetic** (e.g., counting 100-nanosecond interval ticks) so that reconstructions are computationally repeatable and free from floating-point rounding error.

| **Artifact Reliability** | A deterministic confidence classification assigned to each recovered observation based on the integrity and volatility of its source. | Evidence weighting for triage. |
| **Deterministic Integer Timeline** | A chronological sequence built by counting integer timestamp intervals without conversion to floating-point values. | Guarantees exact, repeatable chronology. |
| **Signal Conversion** | The transformation of raw registry values into discrete, semantically typed forensic observations via a structured conversion operation. | Bridges raw data and interpretable intelligence. |
| **Allowlisted Path Resolution** | A boundary-checking protocol that resolves all file paths against an explicit set of authorized base directories before hive access is granted. | Preserves chain-of-custody and prevents path traversal. |
| **RegRipper Interface** | An isolated execution gateway that launches external parsing plugins using strictly validated argument lists. | Secure, deterministic integration of third-party instruments. |
| **Bounded Pattern Matching** | Pattern recognition using length-limited, exact-match templates that eliminate exponential backtracking during text analysis. | Ensures analysis terminates in predictable time. |

> 【Scientific Note】
> This module occasionally employs concepts from semiotics—specifically the interpretive frameworks of **Peirce** (theory of signs), **Eco** (codes and interpretation), and **Grice** (cooperative principles and implicature). These terms describe the **epistemological interface** between raw data and the investigator's conclusion. They are **not mystical constructs**. Think of a registry key as a physical sensor: it outputs a voltage (raw bytes). Peirce asks *what kind of sign* the voltage represents. Eco asks *which cultural/technical code* translates that voltage into a meaningful reading. Grice asks *what cooperative assumption* allows us to trust the sensor was not deliberately spoofed. In digital forensics, this is methodological rigor—calibrating the instrument and validating the channel—no different from spectroscopy or seismology. A **logical fracture** is simply an anomaly where the sensor output violates expected cooperative constraints, indicating tampering or system malfunction.

## ESPAÑOL

### ¿Qué es este módulo?

Este módulo es un **motor determinista de reconstrucción forense** diseñado para extraer, clasificar y ordenar temporalmente evidencia digital de los archivos de registro (*hives*) de Windows. Funciona como un instrumento analítico que trata las entradas del registro como lecturas de sensores emitidas por el sistema operativo. Para prevenir la contaminación de la evidencia, el motor aplica validación estricta de entradas, restringe el acceso a archivos a directorios explícitamente autorizados e invoca herramientas externas de análisis mediante vectores de argumentos aislados —nunca a través de interpretación de shell. Todo el razonamiento temporal se realiza con **aritmética entera determinista** (por ejemplo, contando intervalos de *ticks* de 100 nanosegundos), de modo que las reconstrucciones son computacionalmente repetibles y libres de error por redondeo de coma flotante.

## РУССКИЙ

### Что это за модуль?

Данный модуль — **детерминированный движок форензической реконструкции**, предназначенный для извлечения, классификации и хронологического упорядочения цифровых улик из кустов реестра Windows. Он функционирует как аналитический инструмент, рассматривающий записи реестра как показания датчиков, испускаемых операционной системой. Для предотвращения загрязнения улик движок применяет строгую валидацию входных данных, ограничивает доступ к файлам явно авторизованными директориями и вызывает внешние инструменты разбора через изолированные векторы аргументов — никогда через интерпретацию оболочки.

Всё временное рассуждение выполняется с **детерминированной целочисленной арифметикой** (например, подсчёт интервалов в 100-наносекундных тиках), благодаря чему реконструкции вычислительно воспроизводимы и не содержат ошибок округления с плавающей запятой. Привязанное сопоставление паттернов с шаблонами ограниченной длины исключает экспоненциальный откат при текстовом анализе, гарантируя завершение в предсказуемое время.

Инвариант Добера, лежащий в основе модуля, требует, чтобы каждый форензический артефакт был классифицирован с явно указанной степенью надёжности, основанной на целочисленных метриках, а не на интуитивных оценках — что делает выводы проверяемыми и воспроизводимыми в суде.

## 中文

### 这是什么模块？

本模块是一个**确定性取证重建引擎**，旨在从Windows注册表蜂巢（Registry Hive）中提取、分类和按时序排列数字证据。它作为分析仪器运行，将注册表条目视为操作系统发出的传感器读数。为防止证据污染，引擎强制执行严格的输入验证，将文件访问限制在明确授权的目录中，并通过隔离的参数向量调用外部解析工具——从不通过shell解释。

所有时间推理均使用**精确整数运算**执行（例如，计数100纳秒间隔的滴答），从而确保重建在计算上可重复，且不含浮点舍入误差。有界模式匹配使用长度受限的精确匹配模板，消除文本分析中的指数级回溯，保证分析在可预测时间内完成。

模块的道伯特不变量要求每个取证工件均以基于整数指标的明确可靠性分类来标记，而非直觉判断——使结论在法庭上可验证且可重现。

> **【科学说明】**
> 皮尔斯（Peirce）、艾柯（Eco）和格赖斯（Grice）的术语并非神秘主义，而是形式化的分析机制。如同光谱仪将光子相互作用转换为离散整数计数，本模块将证据信号转换为确定性整数分数。精确整数运算确保法庭可重现性。取证工件链的逻辑断裂以整数标志事件形式被检测。
