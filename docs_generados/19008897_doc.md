**Glossary**

1. **Deployment delta** — A verified difference set applied to an existing system to update functionality without replacing the entire artifact.
2. **Non-executable manifest** — A declarative file that provides integration instructions but does not perform runtime operations itself.
3. **Source-amendment block** — A discrete, bounded unit of code substitution designed to alter a specific logic pathway.
4. **Forensic bridge** — A software intermediary that translates or correlates evidence between distinct analytical subsystems.
5. **Chain-of-custody integrity** — The uninterrupted documentation and protection of evidence from collection through processing to reporting.
6. **Correlation bridge** — A connector that maps identifiers or features across heterogeneous datasets in a forensic workflow.
7. **Fixed locus** — An unambiguous positional coordinate within a file where an amendment must be inserted.
8. **Deterministic modification** — A change that produces an identical, reproducible outcome across every integration instance.
9. **Patch manifest** — A controlled inventory of amendments required to move a system from a known baseline to a target state.
10. **Processing pipeline** — The sequential array of automated stages through which digital evidence is ingested, transformed, and analyzed.
