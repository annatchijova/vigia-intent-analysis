术语表：
- **取证工件**：任何处于调查中的数字对象。在本系统中，取证工件被视为一组结构化的符号集合。
- **行为指纹**：由习惯行为而非静态标识符构建的确定性身份签名。
- **语料库**：用于归纳学习规范的历史数据集。
- **偏差**：对既定整数基准线的可测量偏离；即预期行为中的逻辑断裂。
- **确定性整数运算**：仅限于整数的计算机制，确保所有取证计算结果完全可复现。
- **直方图**：按整数区间分箱的频数分布。
- **阈值**：区分正常变化与可行动异常的固定整数边界。
