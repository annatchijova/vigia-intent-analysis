**ENGLISH**  
Module `run_adversarial_tests.py` executes adversarial assumption fuzzing within the VIGIA framework. The procedure systematically violates the system’s epistemological axioms to observe failure modes under broken premises. It does not evaluate probabilistic drift; instead, it deterministically injects contradictions into knowledge representations to record inferential collapse behavior. Scientific note: results indicate boundary conditions of inferential validity, not statistical variance.

**Glossary**  
- **Adversarial Assumption Fuzzing**: Targeted violation of foundational premises to stress-test reasoning architectures.  
- **Epistemological Axiom**: Foundational proposition assumed true within the system’s knowledge model.  
- **Failure Mode**: Specific manner in which a system malfunctions under specified conditions.  
- **Deterministic Injection**: Precise, reproducible introduction of anomalous inputs without randomness.  
- **Knowledge Representation**: Formal structure encoding information for machine reasoning.  
- **Inferential Collapse**: Catastrophic breakdown of logical consequence derivation.  
- **Boundary Condition**: Limit at which a model’s behavior changes qualitatively.  
- **Inferential Validity**: Extent to which conclusions necessarily follow from premises.  
- **Broken Premise**: Deliberately violated axiom used to test robustness.  
- **Scientific Note**: Authorial annotation distinguishing observed mechanism from statistical artifact.
