**ENGLISH**  
`vigia/sift/sans_phase.py` is a support module within the VIGIA digital-forensics architecture. Situated in the SIFT feature-extraction submodule, it performs deterministic preprocessing of evidentiary media. The module normalizes input signals by abstracting phase-invariant characteristics through discrete integer transforms, yielding reproducible descriptors. This architecture guarantees bitwise consistency across computational environments, preserving chain-of-custody requirements. It serves as an ancillary pipeline stage, supplying standardized inputs to downstream analytical components without introducing non-deterministic approximations.

**Glossary**

- **Digital forensics / Forense digital / Цифровая криминалистика / 数字取证** — Scientific discipline devoted to the recovery, preservation, and analysis of digital evidence.
- **Deterministic system / Sistema determinista / Детерминированная система / 确定性系统** — Computational process in which identical inputs invariably produce identical outputs without stochastic variation.
- **Phase-invariant / Invarianza de fase / Инвариантность к фазе / 相位不变性** — Property of a signal descriptor that remains unchanged under phase shifts.
- **Discrete integer transform / Transformación entera discreta / Дискретное целочисленное преобразование / 离散整数变换** — Mathematical mapping restricted to integral arithmetic to ensure unambiguous representation.
- **Bitwise consistency / Consistencia bit a bit / Побитовая идентичность / 位级一致性** — Exact equality of binary output across independent computational executions.
- **Chain of custody / Cadena de custodia / Цепочка сохранности / 证据保管链** — Documented evidentiary trail guaranteeing integrity from collection to courtroom presentation.
- **SIFT** — Scale-Invariant Feature Transform; algorithm for detecting and describing local image features.
- **Evidentiary media / Medio probatorio / Доказательственный носитель / 证据载体** — Physical or logical container holding potential digital evidence.
- **Pipeline stage / Etapa del pipeline / Звено конвейера / 流水线阶段** — Discrete sequential step within an analytical processing workflow.
- **Non-deterministic approximation / Aproximación no determinista / Недетерминированное приближение / 非确定性近似** — Estimation method yielding variable results across repeated executions.
