**Glossary**

1. **Chain of Custody** (*Cadena de custodia / Цепочка хранения / 保管链*) — Chronological documentation establishing the seizure, control, transfer, and analysis integrity of evidentiary material.

2. **CLI** (*Interfaz de línea de comandos / Интерфейс командной строки / 命令行接口*) — Deterministic, text-based analyst-to-system control interface.

3. **Deterministic System** (*Sistema determinista / Детерминированная система / 确定性系统*) — Computational regime producing identical, predictable outputs from identical inputs and states.

4. **Digital Forensics** (*Forense digital / Цифровая криминалистика / 数字取证*) — Scientific discipline concerned with the recovery, validation, and investigation of digital artifacts.

5. **Evidence Acquisition** (*Adquisición de evidencias / Изъятие доказательств / 证据获取*) — Methodical, forensically sound collection of digital evidence preserving original integrity.

6. **Orchestration** (*Orquestación / Оркестрация / 编排*) — Automated coordination and sequencing of discrete investigative tasks.

7. **Reproducibility** (*Reproducibilidad / Воспроизводимость / 可复现性*) — Capacity to re-execute an analytical process and obtain identical, verifiable outcomes.

8. **Support Module** (*Módulo de soporte / Вспомогательный модуль / 支持模块*) — Auxiliary framework component furnishing non-primary, enabling functionality.

9. **Structured Directive** (*Directiva estructurada / Структурированная директива / 结构化指令*) — Precisely formatted, unambiguous command issued by a human investigator.

10. **Workflow** (*Flujo de trabajo / Рабочий процесс / 工作流*) — Defined, repeatable sequence of procedural operations within an investigative pipeline.
