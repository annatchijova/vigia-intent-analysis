**ENGLISH**  
The `scripts/convert_break_cases.py` module performs deterministic migration of legacy VIGIA_BREAK datasets into the canonical EBS v1 schema. Break cases constitute controlled experiments that isolate specific capabilities of the forensic analysis engine for rigorous evaluation. It maps obsolete identifiers to standardized forensic entities, assigns capability scores, and enforces the prescribed hierarchical structure. Because the transformation is rule-based and non-stochastic, output remains fully reproducible for a fixed input.
