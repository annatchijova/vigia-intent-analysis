**ENGLISH**  
`vigia/phonetic_loader.py` is a deterministic ingestion module that unifies phonetic dictionary loading into a single canonical pathway. It resolves source-path fragmentation, enforces schema validation, and supplies validated phoneme-to-grapheme mappings to downstream VIGÍA forensic pipelines.

**ESPAÑOL**  
`vigia/phonetic_loader.py` es un módulo de ingestión determinista que unifica la carga del diccionario fonético en una vía canónica única. Resuelve la fragmentación de rutas fuente, aplica validación de esquemas y provee mapeos fonema-grafema validados a las canalizaciones forenses de VIGÍA.
