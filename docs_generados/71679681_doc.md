## ENGLISH

### What Is This Module?

This module is a **deterministic forensic reconstruction engine** designed to extract, classify, and temporally order digital evidence from Windows Registry hives. It operates as an analytical instrument that treats registry entries as sensor readings emitted by the operating system. To prevent evidence contamination, the engine enforces strict input validation, confines file access to explicitly authorized directories, and invokes external parsing tools via isolated argument vectors—never through shell interpretation. All temporal reasoning is performed with **deterministic integer arithmetic** (e.g., counting 100-nanosecond interval ticks) so that reconstructions are computationally repeatable and free from floating-point rounding error.

> 【Scientific Note】
> This module occasionally employs concepts from semiotics—specifically the interpretive frameworks of **Peirce** (theory of signs), **Eco** (codes and interpretation), and **Grice** (cooperative principles and implicature). These terms describe the **epistemological interface** between raw data and the investigator’s conclusion. They are **not mystical constructs**. Think of a registry key as a physical sensor: it outputs a voltage (raw bytes). Peirce asks *what kind of sign* the voltage represents. Eco asks *which cultural/technical code* translates that voltage into a meaningful reading. Grice asks *what cooperative assumption* allows us to trust the sensor was not deliberately spoofed. In digital forensics, this is methodological rigor—calibrating the instrument and validating the channel—no different from spectroscopy or seismology. A **logical fracture** is simply an anomaly where the sensor output violates expected cooperative constraints, indicating tampering or system malfunction.

## ESPAÑOL

### ¿Qué es este módulo?

Este módulo es un **motor determinista de reconstrucción forense** diseñado para extraer, clasificar y ordenar temporalmente evidencia digital de los archivos de registro (*hives*) de Windows. Funciona como un instrumento analítico que trata las entradas del registro como lecturas de sensores emitidas por el sistema operativo. Para prevenir la contaminación de la evidencia, el motor aplica validación estricta de entradas, restringe el acceso a archivos a directorios explícitamente autorizados e invoca herramientas externas de análisis mediante vectores de argumentos aislados —nunca a través de interpretación de shell. Todo el razonamiento temporal se realiza con **aritmética entera determinista** (por ejemplo, contando intervalos de *ticks* de 100 nanosegundos), de modo que las reconstrucciones son computacionalmente repetibles y libres de error por redondeo de coma flotante.
