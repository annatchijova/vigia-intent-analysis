- **Firstness / Secondness / Thirdness**: Три универсальные категории опыта Чарльза Сандерса Пирса. Здесь они работают как последовательные фильтры: сырое восприятие, дифференциальная реакция и интерпретативный синтез.
- **Геополитический анализ**: Оценка того, соответствует ли паттерн вторжения известным профилям стратегического или государственного обмана.
- **MIN_CONFIDENCE**: Конфигурируемый целочисленный порог. Поскольку система избегает арифметики с плавающей точкой, достоверность выражается целым числом на фиксированной шкале.
- **Семиотика**: Строгая формальная наука о знаках, значении и коммуникации, разработанная Пирсом и развитая Эко.

【Научное примечание】
Терминология Пирса, Эко и Грайса не является мистикой, литературной метафорой или эзотерической философией. Это формальный семиотический аппарат, функционирующий аналогично калиброванной матрице датчиков. Категории Пирса действуют как этапы обработки сигналов: **Firstness** — захват сырого сигнала; **Secondness** — дифференциальное срабатывание при превышении сигналом базовой линии; **Thirdness** — синтез паттернов, присваивающий значение сработавшему сигналу. Коды Эко служат калибровочными схемами для интерпретации знаков, а максимы Грайса выступают в роли протоколов фильтрации шума для коммуникативного намерения. Внутри данного модуля эти рамки реализованы как детерминированные логические операторы над целочисленными пространствами состояний, а не как расплывчатые аналогии.

### 这是什么模块？
`vigia/vigia_core.py` 是 VIGÍA 取证系统的中央处理单元。它编排一个确定性的六阶段调查流水线。该模块不依赖可能引入舍入误差且不可复现的概率浮点分数，而是采用确定性整数运算与精确符号逻辑。它将数字取证工件依次送入结构化循环：原始描述、异常检测、意图溯因推断、地缘政治假旗评估、对抗性反驳与最终裁决。

**核心概念：**

| 阶段 | 科学功能 | 确定性机制 |
|---|---|---|
| **第一性 (Firstness)** | 取证工件的原始现象学描述 | 从工件中进行整数特征向量提取 |
| **第二性 (Secondness)** | 检测相对于预期基线的偏离 | 对异常进行精确整数计数；不使用近似阈值 |
| **第三性 (Thirdness)** | 操作者意图的溯因综合 | 在离散状态空间上运行的符号推理规则 |
| **地缘政治 (Geopolitical)** | 假旗与归因分析 | 使用整数编码的地缘政治指标进行离散分类 |
| **魔鬼代言人 (Devil's Advocate)** | 结构化反驳与压力测试 | 逻辑否定与对抗性假设检验 |
| **裁决 (Verdict)** | 对案件的最终裁定 | 将整数阈值与 `MIN_CONFIDENCE` 进行比较 |
| **核心引擎类 (VigiaCore)** | 主编排引擎 | 在整数编码阶段之间转移的状态机 |
| **分析案件 (analyze_case())** | 取证调查的入口点 | 将证据原子性地传播通过所有阶段的事务 |
| **最小置信度 (MIN_CONFIDENCE)** | 最低确定性闸门 | 整数尺度（例如 0–100）；低于该值的结果将被拒绝 |

**术语表：**

- **溯因 (Abduction)**：一种逻辑推断方法，从观测事实中选择最佳解释。与演绎和归纳不同。
- **取证工件**：任何接受调查的数字对象——文件、日志、网络数据包或内存段。本模块将其作为离散、可枚举的单位处理。（必须使用“取证工件”，不可使用“制品”。）
- **魔鬼代言人**：一个形式化的反驳阶段，试图推翻主流假设以确保稳健性。
- **假旗 (False Flag)**：数字入侵中的一种欺骗性做法，攻击者故意留下指向其他行为者的证据。
- **第一性 / 第二性 / 第三性**：查尔斯·桑德斯·皮尔斯 (Charles Sanders Peirce) 定义的三种普遍经验范畴。在此充当顺序过滤器：原始感知、差异反应与解释综合。
- **地缘政治分析**：评估入侵模式是否与已知的国家战略欺骗特征相符。
- **逻辑断裂**：基线与观测之间的确定性逻辑断裂，用于精确定位异常；此处的“断裂”指形式逻辑上的不连续，而非物理裂缝。（必须使用“逻辑断裂”，不可使用“裂缝”。）
- **最小置信度 (MIN_CONFIDENCE)**：可配置的整数阈值。由于系统避免浮点运算，置信度以固定尺度上的整数表示。
- **符号学**：关于指号、意义与交际的严密形式科学，由皮尔斯创立并由艾柯 (Umberto 艾柯) 进一步发展。

【科学说明】
皮尔斯、艾柯与格赖斯 (H.P. 格赖斯) 的术语并非神秘主义、文学隐喻或玄学哲学，而是一套形式化的符号学装置，其运作方式可类比经过校准的传感器阵列：皮尔斯的三个范畴相当于信号处理阶段——**第一性**是原始信号采集，**第二性**是信号超出基线时的差异触发，**第三性**是为触发信号赋予意义的模式综合。艾柯的编码体系相当于指号解读的校准框架，而格赖斯的准则则充当交际意图的噪声过滤协议。在本模块中，这些理论框架被实现为整数状态空间上的确定性逻辑算子，而非模糊的比喻。
