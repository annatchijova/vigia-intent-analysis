**ENGLISH**  
Module `convert_synthetic_cases.py` migrates synthetic forensic datasets from the legacy VIGIA-SYN v1 schema to the canonical EBS v1 format. Originally generated in April via an earlier VIGÍA release, these cases receive updated forensic scores to ensure compatibility with the current AC analytical pipeline. The process preserves evidentiary integrity while standardizing metadata for downstream analysis.
