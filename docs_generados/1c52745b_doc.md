**ENGLISH**  
The `document_integrity` module performs deterministic forensic examination of compound documents (PDF, DOCX). Developed from Case 041 ("El Documento Frankenstein"), it conducts multi-layer structural audits without probabilistic hash comparisons. The `audit_document_integrity` function decomposes files into streams, markup layers, and embedded objects, validating logical consistency against format specifications. Scientific note: Integrity assessments rely on exact, reproducible deterministic operations; no floating-point arithmetic is used. This enables non-programming scientists to verify digital authenticity via objective, layer-wise inspection meeting vision-analysis requirements.
