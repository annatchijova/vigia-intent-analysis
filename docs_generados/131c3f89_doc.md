**ENGLISH**  
This canonical adapter executes the VIGIA forensic pipeline as a deterministic three-stage workflow: Detection, Aggregation, and Decision. It ingests structured evidentiary records via command-line invocation and emits reproducible per-artifact findings. An optional negation handler extends logical coverage. The architecture excludes nondeterministic scoring, ensuring bitwise-consistent outputs across repeated executions. *Scientific note: designed for reproducible digital-forensic analysis.*

**Glossary / Glosario / Глоссарий / 术语表**

1. **Artifact** (Artefacto; Артефакт; 工件): A discrete digital object subjected to forensic examination.
2. **Canonical Adapter** (Adaptador Canónico; Канонический адаптер; 规范适配器): A standardized control interface that orchestrates successive processing stages.
3. **Detection** (Detección; Обнаружение; 检测): The initial stage that identifies salient features within evidentiary data.
4. **Aggregation** (Agregación; Агрегация; 聚合): The intermediate stage that synthesizes dispersed findings into unified sets.
5. **Decision** (Decisión; Решение; 判定): The terminal stage that emits a formal analytical conclusion per artifact.
6. **Deterministic System** (Sistema Determinista; Детерминированная система; 确定性系统): A computational process that produces bitwise-identical outputs from identical inputs.
7. **Evidentiary Record** (Registro Probatorio; Запись улик; 证据记录): A structured data instance encoding collected digital evidence.
8. **Negation Handler** (Gestor de Negación; Обработчик отрицания; 否定处理单元): An optional submodule that evaluates inverse logical conditions.
9. **Pipeline** (Canalización; Конвейер; 流水线): A linear, multi-stage architecture enforcing ordered data transformation.
10. **Reproducibility** (Reproducibilidad; Воспроизводимость; 可复现性): The empirical property ensuring equivalent analytical outcomes across independent runs.
