**ENGLISH**  
`run_calibration.py` performs empirical calibration of the VIGÍA LRCalibrator. It extracts z-scores from the SYN, REAL, and BEN corpora, adjusts the LRCalibrator, saves the model to `models/calibrated_lr.json`, and updates `models/calibration_metadata.json` with quality metrics. The procedure ensures Daubert reproducibility by fixing the random seed and versioning all inputs.  
*Scientific note:* Deterministic reproducibility is achieved via fixed-seed pseudo-random generation and input versioning, precluding stochastic variability in calibration.
