**ENGLISH**  
`vigia/sandbox.py` provides a self-contained execution substrate for digital-forensic pipelines. It launches external processes under strict deterministic resource caps—memory and CPU time—enforced via POSIX `setrlimit` hard limits. The module replaces the missing `vigia.security.sandbox` dependency using only the Python standard library (`asyncio`, `subprocess`, `resource`). It offers asynchronous, resource-bound pattern search (grep) and process isolation. All thresholds are exact integers; enforcement logic uses no floating-point approximation.

**Glossary / Glosario / Глоссарий / 术语表**

1. **Sandbox / Entorno aislado / Песочница / 沙箱:** Isolated execution environment preventing host-system modification.  
2. **setrlimit:** POSIX kernel interface enforcing per-process hard resource ceilings.  
3. **Orphan dependency / Dependencia huérfana / Осиротевшая зависимость / 孤儿依赖:** Referenced module absent from the codebase.  
4. **Deterministic limit / Límite determinista / Детерминированное ограничение / 确定性限制:** Bound yielding identical outcomes across equivalent executions.  
5. **Hard limit / Límite duro / Жёсткий лимит / 硬限制:** Kernel-enforced ceiling that processes cannot exceed.  
6. **Resource cap / Tope de recursos / Потолок ресурсов / 资源上限:** Maximum allocable quantity of a system resource.  
7. **Process isolation / Aislamiento de procesos / Изоляция процессов / 进程隔离:** Separation of address spaces to contain faults.
