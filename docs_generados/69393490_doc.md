**ENGLISH**  
`vigia/core/canonicalize.py` is the sole authoritative source for the VIGÍA canonicalization function. It enforces Canonical Schema v1, a deterministic serialization protocol that standardizes data structure representation prior to SHA-256 hashing. By requiring all subsystems—except independent verifiers—to import this routine, the module ensures bitwise reproducibility of hash inputs across the forensic pipeline.

**Glossary**

1. **Canonicalization** — Deterministic transformation of data into a standard, unique representation.  
2. **Deterministic system** — Process where identical inputs always produce identical outputs without randomness.  
3. **SHA-256 hashing** — Cryptographic one-way function generating a fixed 256-bit digest.  
4. **Invariant** — Condition that remains true before and after module execution.  
5. **Serialization** — Conversion of a data structure into an ordered byte sequence.  
6. **Single source of truth** — Centralized, authoritative definition preventing implementation divergence.  
7. **Bitwise reproducibility** — Exact binary equality of outputs across executions and platforms.  
8. **Forensic pipeline** — Automated sequence of processing stages in digital evidence analysis.  
9. **Independent verifier** — External component validating results without relying on the canonical routine.  
10. **Schema v1** — Version 1 specification of the canonical data format.
