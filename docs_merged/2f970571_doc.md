### ENGLISH

**What Is This Module?**
This module is the secure archive of the VIGÍA system. Imagine a laboratory logbook that not only stores experimental records but also verifies that no one has tampered with the pages. Its sole job is to write and read structured records to a single SQLite file on disk, ensuring that every piece of evidence—such as an ACP profile, a document history, or a Daubert audit entry—is preserved with cryptographic rigor and access control. It acts as a digital evidence locker: one gatekeeper per computer process, preventing conflicting edits and guaranteeing that analysts can reconstruct exactly what happened, when, and in what order.

**Glossary**
- **ACP (Adversarial Communication Profile)**: A forensic template that quantifies stylistic and semantic markers of a specific threat actor or bot.
- **Audit Trail (Daubert)**: A chronologically ordered, tamper-evident log satisfying legal standards for scientific evidence admissibility.
- **Deterministic Integer Arithmetic**: Calculations performed with whole numbers (counts, thresholds, permissions) that yield exactly the same result on every execution, free from rounding or representation error.
- **MCP (Manipulation Confidence Parameter)**: A scalar metric derived from linguistic features; updates exceeding the fixed rational threshold of 2.5 are categorically refused.
- **Singleton Pattern**: An architectural constraint allowing only one manager instance per process, thereby serializing all database access through a single controlled point.
- **SIFT Workstation**: A standardized Ubuntu-based digital forensics environment maintained by SANS; exporting to this format enables third-party verification.
- **Sliding Window**: A data-management protocol that discards the oldest record when the count per emitter reaches exactly 20, maintaining a constant sample depth.
- **SQLite**: A self-contained, serverless relational database engine storing tables in a single file.
- **WAL (Write-Ahead Logging)**: A transactional mechanism ensuring durability by writing changes to a separate journal before committing them to the primary database file.

**术语表**
- **ACP（对抗性通信侧写 / Adversarial Communication Profile）**：对特定威胁行为体或机器人的风格与语义标记进行量化取证的模板。

- **确定性整数运算**：使用整数（计数、阈值、权限）进行的计算，每次执行结果完全一致，不存在舍入或表示误差。
- **MCP（操控置信度参数 / Manipulation Confidence Parameter）**：由语言特征导出的标量指标；超过固定有理数阈值 2.5 的更新将被明确拒绝。
- **单例模式（Singleton）**：只允许每个进程存在一个管理器实例的架构约束，从而将所有数据库访问串行化至单一受控点。
